# QCA NSS PORTID bridge

该内核模块把指定的 QCA DSA 用户端口注册为 NSS PORTID 动态接口，供 ECM 通过 NSS 公共 netdev 映射获取接口号。

当前静态映射：

- `wan` → QCA 交换机端口 5 → GMAC 1
- `lan1` → QCA 交换机端口 1 → GMAC 2

配套的 GMAC 补丁将 ipq806x 数据面打开模式切换为 `NSS_GMAC_MODE2`，使物理接口使用 NSS PORTID 接收路径。

模块具备以下安全边界：

- 等待 DSA 用户网卡注册后再绑定；
- 动态接口分配、端口注册、固件配置任一步失败都会回滚；
- 网卡注销和模块卸载时执行反配置、注销、释放引用和动态接口回收；
- 不修改用户空间网络配置，不执行重启。

本模块仅完成源码适配，使用前必须完成与当前内核、NSS 驱动和固件版本匹配的编译及独立加载验证。
